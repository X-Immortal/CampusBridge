# M2 · UI Schema 规范

> 门槛：**≥4 类 Schema**、受限词汇表、白名单、校验器、**≥2 类任务视图**。
> 课件出处：05 p2、03 p72、05 p75。

**核心红线**：模型只生成**声明式 Schema**，客户端只渲染**白名单组件**。**绝不**在线执行模型生成的 ArkTS / JS / SQL。

---

## 一、传输信封

```jsonc
{
  "schemaVersion": "1.0",     // 客户端只接受已知版本，其他一律降级到固定页面
  "taskId": "T-1024",
  "taskVersion": 5,           // 卡片绑定的业务快照版本，旧版本禁止提交
  "cardId": "card-7",
  "kind": "confirmation",     // clarification | comparison | confirmation | progress
  "blocks": [ /* 见下 */ ],
  "actions": [
    { "actionId": "publish", "kind": "primary", "requiresConfirmation": true }
  ]
}
```

**未声明字段在协议 1.0 中一律拒绝。** 扩展必须显式升版本。

---

## 二、组件白名单（受限词汇表）

客户端只认这些。**不在表里的一律拒绝渲染，并记一条拒绝事件。**

| 组件 | 用途 | 必填属性 | 禁止 |
|---|---|---|---|
| `Text` | 说明文字 | `text` | 超长文本（>N 字截断并提示） |
| `Field` | 可编辑字段 | `field`, `label`, `source` | 绑定不存在的字段 |
| `Choice` | 单选选项 | `options`, `onSelect` | 选项来自模型杜撰（必须来自业务数据） |
| `Summary` | 确认摘要 | `rows` | 隐藏关键字段（价格/范围/对象） |
| `Progress` | 进度 | `step`, `state` | 伪造成功状态 |
| `Button` | 动作 | `actionId` | 绑定危险 Action 而不 `requiresConfirmation` |

### 白名单校验的三条硬规则

1. 组件名不在表里 → 拒绝整个 Schema（不是静默丢弃那一个块）
2. `Field.field` 不在当前 Task 模型里 → 拒绝
3. `Button.actionId` 绑到高风险的 Action 却没有确认 → 拒绝

## 三、四类卡片

| 类型 | 什么时候出现 | 用户能做什么 | **不能**做什么 |
|---|---|---|---|
| 澄清 `clarification` | 缺时间/地点/预算，或需要选响应者 | 选选项、也可以改用自然语言或表单补 | 直接改订单 |
| 比较 `comparison` | 需求补齐、还没选服务 | 选邀请对象 | 暗示"已成立" |
| 确认 `confirmation` | 发送邀请、最终确认 | 对**特定版本**授权一个动作 | 授权别的动作 |
| 进度 `progress` | 已发布或履行中 | 看真实进展、进详情 | 伪造完成 |

**≥2 类任务视图**指同一任务在不同场景下的呈现要不同，例如：
- 观点 A：首次表达（大输入框 + 澄清卡）
- 观点 B：任务进行中（进度 + 沟通 + 评价）
- 观点 C：宽屏/平板（列表密度更高，适合扫描确认）

| 视图 | 适用场景 | 和别的视图差在哪 |

## 四、校验器要覆盖的失败用例

| # | 输入 | 期望 |
|---|---|---|
| 1 | 非白名单组件 | 拒绝 |
| 2 | 绑定不存在的字段 | 拒绝 |
| 3 | 高风险 Action 缺确认 | 拒绝 |
| 4 | `schemaVersion` 不认识 | 降级到固定页面 |
| 5 | 体积超限 / 卡数超限 | 拒绝或截断 |
| 6 | `taskVersion` 落后于当前 | 标记过期，禁用来按钮 |
| 7 | UI 展示值 ≠ 工具参数摘要 | 拒绝执行 |
| 8 | 隐藏关键字段（价格/范围） | 拒绝 |

## 五、九条最小自动化测试（课件 03 p71，一条都不能少）

- [ ] 非白名单组件被拒绝
- [ ] 绑定不存在字段时失败
- [ ] 高风险 Action 缺少确认时失败
- [ ] Task Model 更新后旧授权失效
- [ ] 同一幂等键只产生一次业务事实
- [ ] 刷新后恢复 `lastStableVersion`
- [ ] 投影自动移除禁止动作
- [ ] UI 展示值与工具参数摘要一致
- [ ] 工具失败时不得写入成功事实

## 六、降级三级

| 级别 | 触发条件 | 用户看到什么 | 谁决定的 |
|---|---|---|---|
| L0 正常 | 模型可用且 Schema 通过 | 生成式卡片 | |
| L1 规则 | 模型超时 / 输出不合法 | 规则整理出的卡片，**明确标注"规则整理"** | |
| L2 固定页面 | Schema 版本不认识 / 渲染失败 | 传统表单 | |

**L1 和 L2 必须现场能演**，而且界面要说清现在是哪一级 —— 不许把规则结果伪装成模型成功。
