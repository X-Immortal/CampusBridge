# 开发环境说明

本文档用于指导团队成员完成 CampusBridge 项目的本地开发环境搭建。

## 一、基础软件要求

请先确保本机已经安装以下软件：

- Git
- JDK 17
- Maven 3.9.x
- Node.js 20 及以上版本
- npm
- IntelliJ IDEA 或 VS Code

建议版本：

- Java：17
- Maven：3.9.x
- Node.js：20 及以上

## 二、环境变量配置

### 1. Java

安装 JDK 后，请确认以下命令可以正常运行：

```powershell
java -version
javac -version
```

建议配置环境变量：

- `JAVA_HOME`：指向 JDK 安装目录
- `Path` 中包含 `%JAVA_HOME%\\bin`

### 2. Maven

安装 Maven 后，请确认以下命令可以正常运行：

```powershell
mvn -version
```

建议配置环境变量：

- `MAVEN_HOME`：指向 Maven 安装目录
- `Path` 中包含 `%MAVEN_HOME%\\bin`

### 3. Node.js

安装 Node.js 后，请确认以下命令可以正常运行：

```powershell
node -v
npm -v
```

## 三、获取项目

克隆仓库后进入项目根目录：

```powershell
git clone <仓库地址>
cd campusbridge
```

## 四、前端环境初始化与运行

进入前端目录，安装依赖：

```powershell
cd frontend
npm install
```

启动前端开发服务器：

```powershell
npm run dev
```

正常情况下，终端会给出本地访问地址，一般为：

```text
http://localhost:5173
```

前端构建检查命令：

```powershell
npm run build
```

前端代码风格检查命令：

```powershell
npm run lint
```

## 五、后端环境初始化与运行

进入后端目录，执行测试：

```powershell
cd backend
mvn clean test
```

后端代码风格检查命令：

```powershell
mvn checkstyle:check
```

启动后端服务：

```powershell
mvn spring-boot:run
```

正常情况下，后端会运行在：

```text
http://localhost:8080
```

可以通过以下接口验证服务是否正常启动：

```text
http://localhost:8080/api/health
```

## 六、项目初始化验证

若以下检查均通过，则说明本地环境搭建成功：

1. `npm run dev` 能正常启动前端
2. `npm run lint` 能通过前端代码风格检查
3. `npm run build` 能正常完成前端构建
4. `mvn checkstyle:check` 能通过后端代码风格检查
5. `mvn clean test` 能通过后端测试
6. `mvn spring-boot:run` 能正常启动后端
7. 浏览器可访问前端页面和 `/api/health` 接口

## 七、开发建议

- 日常开发请优先在 `develop` 分支基础上创建 `feature/*` 分支。
- 提交前请先完成本地风格检查与构建检查。
- AI 辅助生成的内容必须经人工审查后再提交。
