# 演示说明

## 演示目标

展示 CampusBridge 从用户认证、任务发布、接单、完成确认、评价、举报到管理员处理的核心闭环，证明 P0 功能可用，P1 功能基本可演示。

## 方式一：云端体验（推荐）

项目已部署至公网服务器，助教可直接通过浏览器访问，无需本地搭建环境。

**地址：https://campusbridge.top**

| 普通用户（接单者）| `alpha`           | `123456`   | 已认证，可接单 |
| 管理员 | `li_wenhao_admin` | 以数据库实际设置为准 | 角色为 `ADMIN` |

### 云端演示路径

以下六条路径均可在云端直接操作，无需本地启动：

1. **注册登录与认证**：打开首页 → 进入登录页 → 注册或登录 → 个人主页编辑资料 → 提交校园认证
2. **发布任务与筛选**：已认证用户进入发布页 → 填写任务信息 → 发布 → 任务广场筛选查看
3. **接单与状态流转**：切换另一账号 → 找到任务 → 申请接单 → 发布者接受 → 开始任务
4. **完成确认与评价**：接单者提交凭证 → 发布者确认 → 双方评价 → 查看积分变化
5. **举报与裁决**：任务详情举报 → 管理员后台查看 → 裁决处理 → 信用扣分
6. **站内沟通**：任务详情进入会话 → 发送消息 → 消息中心查看通知

> 云端演示建议使用两个浏览器窗口（或普通窗口 + 无痕窗口）分别登录不同账号，方便观察双方交互。

| 项目 | 要求 |

| Maven | 3.9.x |

| npm | 10+ |

后端默认地址：

前端默认地址：


## 核心演示路径

以下路径在本地和云端均可操作。

### 路径一：注册、登录与校园认证

1. 打开登录页（本地 `http://localhost:5173/auth`，云端 `https://campusbridge.top/auth`）
2. 注册发布者账号并登录
3. 进入个人主页
4. 编辑昵称、学院、校区、个人简介
5. 选择校园认证方式：
   - 学生证图片认证
   - 校园邮箱认证
   - 人工审核
6. 使用管理员账号进入管理后台，审批认证申请
7. 普通用户刷新后看到认证状态变为"已认证"

演示重点：

- 登录态持久化
- 认证门禁
- 资料和认证状态联动

### 路径二：发布任务与任务广场筛选

1. 使用已认证发布者账号进入"发布任务"
2. 填写任务标题、描述、校区、地点、截止时间、奖励方式
3. 保存草稿，确认草稿不会公开
4. 重新进入发布页并正式发布
5. 进入任务广场，按分类、状态、报酬类型、关键词筛选
6. 打开任务详情，查看发布者、奖励、地点、截止时间和操作入口

演示重点：

- 未认证用户不能发布任务
- 草稿和正式发布分离
- 列表筛选和详情展示

### 路径三：接单、选择候选人与状态流转

1. 切换到接单者账号
2. 在任务广场找到发布者创建的任务
3. 提交接单申请，填写申请留言
4. 切回发布者账号
5. 打开任务详情，查看候选人列表
6. 接受接单者申请，任务进入 `ACCEPTED`
7. 切换到接单者账号，点击开始任务，任务进入 `IN_PROGRESS`

演示重点：

- 发布者不能接自己的任务
- 一个任务只能选择一个帮助者
- 状态变化写入历史并发送系统通知

### 路径四：完成凭证、确认完成与评价

1. 接单者在任务详情中提交完成说明和凭证
2. 任务进入 `PENDING_CONFIRMATION`
3. 发布者查看完成凭证
4. 发布者确认完成，任务进入 `COMPLETED`
5. 双方进入评价中心或任务详情，提交评分和文字评价
6. 查看用户信用和积分变化

演示重点：

- 完成凭证
- 发布者确认/驳回
- 积分奖励和信用记录
- 双向评价

### 路径五：举报与管理员裁决

1. 普通用户在任务详情中点击举报
2. 填写举报目标、原因和描述
3. 管理员进入"管理后台"
4. 在举报裁决区域查看举报记录
5. 填写裁决说明，选择处理结果
6. 对违规用户扣减信用积分，必要时将任务标记为争议

演示重点：

- 举报入口和表单校验
- 管理员裁决
- 信用扣分和争议联动

### 路径六：站内沟通与消息通知

1. 在任务详情中进入站内沟通
2. 双方发送文本消息
3. 任务状态变化后查看系统通知
4. 进入消息中心查看未读通知聚合

演示重点：

- 禁止绕过平台直接联系的产品约束
- 系统通知由任务事件触发
- 消息中心可以聚合会话通知

## 注意事项

- 后端实际端口为 `8081`，不是旧 README 中的 `8080`。
- 头像上传限制为 5MB（`spring.servlet.multipart.max-file-size: 5MB`）。
- 高风险词如"代考""代签到""作弊"会被内容治理直接拦截，不进入普通任务广场。
- 邮箱验证码在本地配置中默认关闭（`campusbridge.verification.email.enabled: false`），云端以实际配置为准。
- 若管理员入口不可见，请确认当前登录用户角色为 `ADMIN`。
