# 校园互助平台用户访谈提纲+记录

## 访谈问题
1. 你在校园日常生活中，最常遇到、最需要同学帮忙解决的事情有哪些？
2. 你愿意主动为身边同学提供哪些具体、可落地的帮助服务？
3. 你是否使用过校园代取、代买、互助类服务？最不好的一次体验是什么？
4. 如果上线校园互助平台，你最希望优先上线哪一类功能？
5. 你在选择让谁帮忙时，最看重对方哪些能证明靠谱、可信的信息？
6. 你在接受帮助或提供帮助时，最担心发生哪些安全问题或纠纷？
7. 你更接受哪种互助感谢方式？为什么更倾向这种方式？
8. 你认为平台必须具备哪些保障功能，你才会愿意注册并放心使用？

---

## 访谈回答 1
1. 平时上课和自习时间很紧张，最需要同学帮忙代取快递、带饭、打印资料，偶尔也需要提前占个自习座位。
2. 我时间相对灵活，可以帮同学代取快递、带饭，也能解答一些学习问题，分享笔记和复习资料。
3. 之前用过私人代取快递，对方经常拖延、不回消息，甚至把快递放一边不管，体验特别差。
4. 希望平台先做学习资料共享、课程答疑这类学习互助功能，能帮大家提高学习效率。
5. 对方是不是本校学生、口碑好不好，有没有同学真实评价，这样才敢放心托付事情。
6. 物品丢失、个人安全没保障，一旦出现纠纷没人处理，最后只能自己承担损失。
7. 用小礼物、零食表达感谢，不涉及金钱往来，关系更自然，也不会有心理负担。
8. 必须要有严格的校内身份认证和交易安全担保，我才敢在平台上发布需求和接单帮忙。

---

## 访谈回答 2
1. 需要代办证件、交材料、借工具。一个人跑流程太费时间，有人搭把手会方便很多。
2. 一些校内办事流程，可以代交材料、填表格、借工具，也能帮着整理活动所需物资。
3. 之前托人代办手续，对方粗心漏交材料，直接耽误我报名，事后还态度敷衍，非常糟心。
4. 我更想要事务代办、证件办理提醒、设备借用登记、校内跑腿服务这些功能。
5. 我只相信完成过多单任务、有历史记录、可当面确认的人，空口说靠谱我完全不信。
6. 信息被乱传、东西被弄坏、临时被放鸽子，重要事情被耽误，后果很难补救。
7. 我 prefer 互相帮忙、人情互换。这次你帮我，下次我帮你，比送东西更实在也更长久。
8. 平台一定要实名核验、留可追溯记录、有违约惩罚，否则我绝对不会用。
