## BUG-01：管理员入口文案不一致

| 字段 | 内容 |
|---|---|
| 问题现象 | `npm run test:admin` 第 6 个子测试失败，期望 `DashboardShell.vue` 包含“管理后台” |
| 根因分析 | 管理员页面 `AdminView.vue` 使用 `active-label="管理后台"`，但侧边栏导航和首页快捷入口写成“管理中心” |
| 修复方案 | 统一文案为“管理后台” |
| 验证结果 | `npm run test:admin` 通过，`npm run lint` 通过，`npm run build` 通过 |

## BUG-02：前端 lint warning

| 字段 | 内容 |
|---|---|
| 问题现象 | `npm run lint` 对 `App.vue` footer 链接的 `target`、`rel` 属性给出 `vue/max-attributes-per-line` warning |
| 根因分析 | 链接多个属性写在同一行，与 Vue ESLint 规则不一致 |
| 修复方案 | 将 `href`、`target`、`rel` 拆分为多行 |
| 验证结果 | `npm run lint` 通过且无 warning；`npm run build` 通过 |

## BUG-03：任务编辑接口方法不一致

| 字段 | 内容 |
|---|---|
| 问题现象 | OpenAPI 中任务编辑接口为 `PATCH /tasks/{taskId}`，实际后端和前端使用 `PUT /tasks/{taskId}` |
| 根因分析 | P3 API 文档和 P4 实现阶段接口方法未同步 |
| 当前处理 | 保留实际可运行的 PUT 链路，P4 文档记录差异 |
| 验证结果 | `task-publish.test.mjs` 验证编辑模式调用 `updateTask` 通过 |

## BUG-04：头像上传大小配置不一致

| 字段 | 内容                                                                  |
|---|---------------------------------------------------------------------|
| 问题现象 | 头像上传服务允许 5MB，但 Spring multipart 配置为 1MB                             |
| 根因分析 | 业务服务限制和框架入口限制不一致，超过 1MB 的文件无法进入服务层                                  |
| 当前处理 | 改后端配置允许5MB                                                          |
| 验证结果 | 非阻塞问题，列入后续配置修正                                                      |

## BUG-05：敏感任务审核降级

| 字段 | 内容 |
|---|---|
| 问题现象 | 需求文档希望敏感任务进入审核流，当前实现对“代考/代签到/作弊”等关键词直接拦截 |
| 根因分析 | P4 阶段优先保证核心互助任务稳定，敏感任务审核策略被简化为内容治理拦截 |
| 当前处理 | 管理员任务审核接口保留；高风险内容直接拦截，避免违规内容公开 |
| 验证结果 | 内容治理服务能拦截违规关键词；管理员任务审核入口存在 |
