- 实验主题：模块集成与典型 Bug 调试

## 分析结论

### AI 表现较好的场景

- 根据失败日志定位断言来源
- 在多文件中发现命名不一致
- 提醒接口文档、前端封装、后端 Controller 需要三方对齐
- 对配置类问题给出搜索关键词

### AI 表现较差的场景

- 无法替团队判断是否应该改 API 兼容策略
- 容易把“能跑通”误判为“符合文档”
- 对课程交付优先级缺少上下文，需要人工明确 P0/P1/P2

### 会出现只修表象，不修根因的情况

### 有效上下文

AI 调试建议在提供以下上下文后明显变好：

- 完整错误日志
- 失败测试文件路径
- 相关 Controller/API 封装/页面文件
- 当前阶段交付目标和不能大改的约束
