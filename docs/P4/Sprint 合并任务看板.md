# Sprint 合并任务看板

## 说明

- 来源依据：`docs/P1/04-需求规格说明书/需求规格说明书.md`、`docs/P1/05-用例图与详细用例描述/详细用例描述.md`、`docs/P1/06-用户故事与AI辅助实验/用户故事.md`

## 建议落地方式（看板列）

- `Backlog`：未开始任务
- `In Progress`：开发中（限制 WIP，建议每人同时最多 1-2 项）
- `Code Review`：代码评审中
- `Test`：联调与测试中
- `Done`：满足完成标准并已合并
