2. 主要关系

用户关系

  • User 1 - 1 UserProfile
  • User 1 - 0..1 CampusVerification
  • User 使用 UserRole 和 VerificationStatus

任务关系

  • User 1 - 0..* Task，用户发布任务
  • Task 1 - 0..* TaskApplication，任务接收多个申请
  • Task 使用 TaskStatus、TaskCategory、RewardType

闭环关系

  • Task 1 - 0..1 Conversation
  • Conversation 1 - 0..* Message
  • Task 1 - 0..* CompletionProof / Review / CreditRecord

治理关系

  • User 1 - 0..* Report
  • Task 1 - 0..* Dispute
  • Report / Dispute / ModerationCase 使用 ModerationStatus

潜在问题

  • Task 和 TaskLifecycleService 都包含状态流转能力，职责边界需要检查。
  • Report、Dispute、ModerationCase 可能有重叠。
  • targetType、caseType 使用字符串，类型安全不足。
