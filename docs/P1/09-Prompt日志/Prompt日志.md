## 阶段性观察

1. 宽泛 Prompt 适合拿结构，但不适合直接拿来交作业。
2. 真正决定文档质量的不是“AI 写了多少”，而是人工有没有回到问卷和访谈原文做二次判断。
3. 对高风险场景、异常流、处罚规则、范围裁剪和交付结构，最终都需要人工拍板。
4. AI 在本阶段更像“初稿生成器 + 对比工具 + 结构整理器”，而不是能独立完成需求分析的人。
