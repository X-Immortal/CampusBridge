### 2.2 基线

| 项 | 内容 |
|---|---|
| 基线配置 | 例如：所有任务只用纯文本对话，不出卡片 |
| 样本范围 | 哪几条 case / 哪几类 |

| 测量指标 | 完成时间 / 修改率 / 误操作 / 满意度 |
